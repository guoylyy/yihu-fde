## 快速上手（给平台配置者）

**方式 A（推荐）：MCP 直连** —— 后端已内置 MCP Server（`POST /api/mcp`，API Key 鉴权），平台支持 MCP 的话按 `10-mcp-server.md` 配置即可，工具自动发现，跳过手工建 Action。

**方式 B：逐个注册 REST 工具**（平台不支持 MCP 时）：
1. **先解决前置条件**（见 09）：后端公网可达。
2. 在平台注册工具：照 `08-tool-definitions.json` 逐个建 Action，base_url 填后端地址，鉴权选 Bearer Token（登录工具换取）。

两种方式共同的部分：
3. 系统提示词：以 `01` 的角色画像 + 行为准则为骨架，附上 `05` 的越权话术和 `07` 的槽位归一化规则。
4. 知识库：把 `02`、`04`、`06` 整体导入平台知识库（RAG）。
5. 用 `07` 的 21 组样本做 few-shot / 微调语料，再按 `09-C` 的测试集验收。

## 智能体核心设定摘要

- **服务对象**：FDE_ENGINEER 角色的内部工程师，代理其本人身份调用 API（JWT）。
- **会话初始化**：登录 → `GET /api/fde/me` 缓存 engineerId + 项目映射。
- **三条铁律**：①金额/工时/日期写操作前必须复述确认；②403 不重试、说人话指路；③相对日期一律换算为 YYYY-MM-DD。
