# 里程碑路径图：把任务的先后逻辑画出来

> v2.8.0 · 项目详情「规划」Tab · 适用：项目经理每日排任务、工程师看"我现在能做什么"、AI 编程按图取任务

## 1. 它解决什么

以前的里程碑是一条时间轴，任务看板是五列卡片，两者之间**没有逻辑关系**：谁先谁后、谁挡着谁、终点在哪，全靠脑子记。
路径图把一个里程碑下的任务画成一张有向图：

- **节点** = 任务，颜色即状态（绿=完成、橙=生产中、灰=可开始、红边=被挡住、虚线=还在等前置）
- **实线箭头** = 硬依赖（前置没完成，后继就是**阻塞**态）
- **紫色虚线** = 回环（"做完 B 可能回到 A 再迭代"，只表达意图，不阻塞）
- **黑色圆角终点** = 里程碑本身，上面写着「完成定义」

派生出来的三个量不用人维护，系统实时算：

| 量 | 口径 |
|---|---|
| 可开始 ready | 待开始且所有硬依赖前置都已完成 |
| 阻塞 blocked | 未完成且存在未完成的硬依赖前置 |
| 关键路径 | 未完成任务上按预估工期加权的最长链，决定里程碑最早能哪天收口 |

## 2. 界面怎么用

进入任何项目详情，默认落在「规划」Tab：

- **左侧里程碑轨**：每个里程碑显示 完成数 / 可开始数 / 阻塞数，点选切换画布；「全部里程碑」把整个项目画成一张图；「未挂里程碑」看零散任务
- **中间画布**：
  - 拖动节点右侧的把手到另一个节点 → 建依赖（工具栏切换「硬依赖 / 回环」决定建哪种）
  - 会成环的连线会被拒绝，并提示完整环路（如 `#146 → #148 → #149 → #146`）
  - 双击节点进任务详情；「高亮关键路径」「只看未完成」两个开关
  - 「Mermaid」按钮导出流程图文本，贴到文档或喂给 AI
- **右侧侧栏**：选中任务看阻塞来源、前置/后继（可一键解除）、快捷流转；选中边可改类型/写说明/解除；选中终点看完成定义
- **看板 / 列表**：同一份数据的另两种看法。看板卡片带「⛔ 阻塞 · 等 N 个前置」角标

**阻塞是提醒不是锁**：被挡住的任务照样可以点「开始生产」，只是会弹窗让你写一句原因，原因自动记进任务评论。现场抢工常见，硬锁只会逼人删依赖。

## 3. AI 路径图助手

点画布右上「✨ AI 助手」，三个功能，都不是聊天：

1. **生成路径图**：写一段目标（例：本里程碑要把客户对话服务上线：接口评审→后端→前端→联调→灰度），选目标里程碑，AI 会**带着项目已有里程碑与任务**去拆，不重复拆已有的，能把新任务接到已有任务后面。草案先以**紫色虚线幽灵节点**叠在画布上，你可以删任务、改标题/角色/优先级，确认后「应用到项目」才真正落库（任务来源标 `AI`，依赖建硬依赖，同时写一条项目记录）。
2. **补依赖**：对已有任务，AI 提议缺失的先后关系，已存在 / 会成环的建议后端已过滤，勾选后一键建立。
3. **解读路径**：三段大白话——现在能开工什么、谁挡着谁、离终点还差几步今天先做什么。

未配置大模型时面板会提示去「基础配置 → 大模型配置」，不会报错。

## 4. 给 AI 编程 / 智能体：按图取任务

MCP 新增三个工具（详见「MCP 智能体接入」）：

| 工具 | 用途 |
|---|---|
| `get_milestone_roadmap {projectId, milestoneId?}` | 一次拿到 nodes / edges / topoOrder / **ready** / blocked / criticalPath / mermaid |
| `add_task_dependency {predecessorId, successorId, type?, note?}` | 建边，成环返回 9006 与环路 |
| `remove_task_dependency {predecessorId, successorId}` | 删边 |
| `apply_decomposition_draft {projectId, milestoneId?, draft}` | 审核过的草案落库 |

同时 `get_task` 返回 `predecessors / successors / blocked / blockedBy`，`create_task` 支持 `dependsOn: [taskId]`。

推荐的开工姿势：`get_milestone_roadmap` → 从 `ready` 里按优先级挑（关键路径上的优先）→ 做完置 DONE → 再读一次图看解锁了谁。

## 5. 数据口径（给对接方）

- 表 `task_dependencies`：`predecessor_id → successor_id`，`type` = `BLOCKS` | `FEEDBACK`，`note` 说明；软删
- 依赖只能建在**同一项目**的任务之间；任务删除 / 跨项目移动时其所有边自动失效并在评论留痕
- `milestones.goal`：里程碑完成定义（一句话 DoD）
- `tasks.source` 新增枚举 `AI`（AI 面板落库）
- 接口：`GET /api/fde/projects/:id/roadmap?milestoneId=`、`/api/fde/task-dependencies`（GET/POST/PUT/DELETE，`DELETE /pair?predecessorId=&successorId=`）、`POST /api/fde/decomposition/{generate,apply,suggest-dependencies,explain}`
