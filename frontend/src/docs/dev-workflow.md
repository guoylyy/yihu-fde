# 员工开发工作流：从零到交付一条龙

> 这是写给新同事的上手教程。看完并照做，你就能用「平台任务 + AI 协作」的标准流程独立完成 **开会 → 领任务 → 开发 → 回写 → 报工时** 的完整交付循环。全程不需要找人口头教学；卡住了再看最后的 FAQ。

---

## 0. 这套工作流长什么样

团队的所有开发需求都走同一条流水线：

**🎙️ 开会**（需求的唯一起点）→ **🧩 需求梳理**（AI 从纪要提炼，人确认）→ **📋 任务生成**（确认的需求变成看板任务）→ **🔧 开发**（你 + Claude Code 协作）→ **✅ 回写验收**（进度写回平台，经理验收）

你在项目详情页顶部能看到这条流水线的实时状态（工作流面板），自己的进度在「仪表盘 → 我的工作流」。

---

## 1. 平台账号与角色

- 入口：公司控制台（找管理员开账号，初始密码首次登录会强制修改）
- 你的角色一般是 **FDE_ENGINEER（工程师）**：能看到自己参与的项目、自己的任务、自己的工时
- 左侧菜单常用五个：**仪表盘**（我的任务概览）、**开发上手**（环境配置向导）、**项目交付 → 项目管理 / 任务管理 / 工时**

## 2. 怎么开会

需求从会议来。跟客户或内部对齐时：

1. 进入项目 → **会议记录** Tab → 点「添加记录」，填标题、参与人和纪要
2. 已有会议纪要文档（腾讯会议/飞书导出的 md、docx、pdf）可以点「AI 导入纪要」，自动识别字段
3. 保存后点「🤖 梳理需求」，AI 从纪要里提炼需求清单

**技巧**：会上把「谁来做、什么时候要」说清楚，AI 梳理需求时就能直接带出负责人和期限。

## 3. 需求确认怎么点

会议纪要生成后：

1. 纪要卡片上点「🤖 梳理需求」→ AI 把纪要拆成一条条结构化需求
2. 打开「📋 需求清单」抽屉 → 逐条 **确认** 或 **驳回**（也可以先编辑再确认）
3. 确认的需求点「→ 生成任务」，任务会出现在看板的**收件箱**列，描述自动带需求来源

> 需求确认是人的职责——AI 只负责提炼，要不要做、优先级多高，由你和经理拍板。

## 4. 怎么领任务 / 看板五态

任务看板五列，对应任务的一生：

| 状态 | 含义 | 谁操作 |
|---|---|---|
| 📥 收件箱 | 新任务，还没排期 | 经理/你认领 |
| ⏳ 等候生产 | 排好计划（必须填开始/结束日期） | 你 |
| 🔧 生产中 | 正在开发 | 你 |
| ✅ 生产完成 | 开发完，等验收 | 你置为完成 |
| 🏁 已验收 | 经理验收通过 | 经理 |

领任务：看板上把指派给你的任务点开 → 「开始生产」。也可以让 AI 替你做（见下一节的「开工」口令）。

## 5. 开发环境配置（一次性，10 分钟）

去后台 **「开发上手」** 页面，照五步 checklist 走：

1. 点「📦 生成并下载配置包」→ 得到 `fde-dev-kit.zip`
2. 解压后按包里 `README.md` 的说明放置两个文件：`.mcp.json` 放项目根目录，`skills/fde-tasks/` 放 `.claude/skills/` 下
3. 安装 [Claude Code](https://claude.com/claude-code)，让组长把你的 Gitee 账号拉进仓库
4. 在项目目录启动 `claude`，说「开工」——能列出你的平台任务就是通了
5. 回「开发上手」页刷新，前两步会自动点亮

> ⚠️ 配置包里的密钥等同于你的账号身份：不要外传、不要提交进 git 仓库。泄露了就回「开发上手」页重新下载（旧密钥自动作废）。

## 6. Claude Code 日常三口令

| 口令 | 时机 | AI 会做什么 |
|---|---|---|
| **开工** | 每天开始 | 拉你的待办任务 → 你选一个 → 置为生产中 → 拆子任务 |
| （开发中） | 写代码 | 与你协作实现；关键进展自动评论到任务时间线 |
| **收工** | 任务做完 | 汇总做了什么写回任务评论 → 任务置为生产完成 |

## 7. 提交规范：commit 带任务号

提交信息末尾带 `#任务号`：

```
feat: 订单导出增加日期筛选 #123
```

平台同步 Gitee 提交后，会自动把这条提交挂到 #123 任务的时间线上——你的代码贡献自动留痕，不用手工贴链接。

## 8. 怎么报工时

- 入口：**项目交付 → 工时** → 填报（选项目、日期、小时数、工作内容）
- 口径：一天 = 8 小时，半天 = 4 小时；工作内容写具体做了什么，不要只写"开发"
- 也可以在收工时让 Claude Code 帮你报：「帮我报今天 8 小时工时」，它会复述内容跟你确认后提交
- 提交后等经理审批，被驳回会收到站内通知

## 9. 常见坑 FAQ

**Q：Claude Code 说「开工」没反应 / 报 401？**
密钥失效了（可能重新下载过配置包）。回「开发上手」页重新下载，替换 `.mcp.json`。

**Q：看不到任何任务？**
①确认任务指派给了你；②确认你被加进了项目成员（找经理）。

**Q：转「等候生产」提示必须填时间？**
这是规则：排期任务必须有计划开始/结束日期，弹窗里填上即可。

**Q：提交了代码但任务时间线上没有？**
①检查 commit message 是否带 `#任务号`；②仓库要先在项目详情「代码仓库」Tab 里登记过；③同步有几分钟延迟。

**Q：AI 干了错事怎么办？**
所有写操作都在平台留痕（评论/时间线），发现不对及时在任务下评论说明并 @经理。不可逆操作（删除等）AI 必须先问你，直接拒绝即可。

## 附：10 分钟跟练路径

新人第一天建议完整走一遍（用演示项目或你自己的项目）：

1. **[2 分钟]** 「开发上手」页下载配置包，按 README 放好文件
2. **[1 分钟]** 项目 → 会议记录 → 「🎙️ 开会」，对着麦克风说一段假需求（如"我们需要给官网加一个深色模式，下周五之前上线，我来做"），结束会议
3. **[1 分钟]** 等纪要生成 → 「🤖 梳理需求」→ 需求清单里确认它 → 生成任务
4. **[3 分钟]** 终端启动 `claude` 说「开工」→ 选中刚才的任务 → 让它拆两个子任务
5. **[2 分钟]** 随便改一行代码提交，commit message 带上任务号 → 说「收工」
6. **[1 分钟]** 回平台看任务时间线（评论+提交关联都在）→ 报一条工时

走完这六步，你已经用过了这套工作流的全部环节。之后的真实项目，只是把第 2 步换成真会议、第 4 步换成真开发。
