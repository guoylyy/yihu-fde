# Agent 协作：注册你的 Agent，把过程资源沉淀回系统

> v1.6.0 起，FDE 系统支持员工注册自己的 Agent。Agent 拿到专属 API Key 后，
> 不仅能替你操作系统（查项目、报工时、记纪要），还能把工作过程中的资源——
> **对话记录、研究结论、客户聊天记录**——随手沉淀回系统，汇聚成团队共享的项目过程资料。

## 为什么要注册

不注册也能用（用以虎 One 个人中心的 API Key 经平台调 MCP），但注册后：

- **一体一 Key**：每个 Agent 独立凭证，可单独停用/换 Key，泄露不殃及其他；
- **来源可辨**：Agent 写入的记录、回传的对话都标注「谁的哪个 Agent」，团队看时间线一目了然；
- **活动留痕**：Agent 经 MCP 的每次成功调用留审计流水，后台可查活跃度与沉淀计数。

Agent 的权限与数据范围**完全等同注册它的员工本人**——注册不扩权，只加身份。

## 注册步骤

1. 登录控制台，进入左侧菜单「**Agent 协作**」；
2. 点「注册 Agent」，填名称（如"调研助手"）、所属平台（OpenHex / Claude Code / 扣子 / 自研）、能力标签；
3. 注册成功后弹出**专属 API Key（明文只显示这一次）**，复制保存；
4. 把 Key 配置到 Agent 侧的 MCP 连接里：

```
POST https://<域名>/api/mcp
Authorization: Bearer fde_xxxxxxxxxxxxxxxx
```

支持 MCP 的平台会自动拉取全部工具清单（110 个）。基础接入方式与「MCP 智能体接入」文档一致。

## 让 Agent 沉淀数据（v1.6.0 新增工具）

| 工具 | 用途 |
|---|---|
| `log_agent_conversation` | 把 Agent 与你的一段对话整段回传留存；带 `projectId` 会进项目时间线，团队可回看。长对话可分段续传 |
| `add_research_note` | 技术调研/方案比较/踩坑结论归档到项目（Markdown：课题/结论/参考链接） |
| `add_project_record` | 过程记录通用入口；v1.6.0 起类型新增 `CHAT`（客户聊天记录）与 `RESEARCH`（研究记录） |
| `get_my_agent_profile` | Agent 查看自己的注册档案与沉淀计数 |

建议在 Agent 的系统提示词里加一句：**「围绕项目的重要讨论、调研结论，干完活主动沉淀回系统」**——
系统侧 MCP instructions 也已内置该约定。

## 在哪里看沉淀的数据

- **项目详情 → 记录**：统一时间线，按类型筛选（会议/对接/现场/资料/聊天/研究），Agent 沉淀的条目带 🤖 来源标签；
- **项目详情 → 记录 → 🤖 Agent 对话**：挂到本项目的对话会话，点开可看完整轮次；
- **客户管理 → 客户详情 → 交互史**（v1.6.1）：该客户名下所有项目的对接/聊天/会议记录与 Agent 对话聚合，打单/复盘前一页看全；
- **Agent 协作页**：每个 Agent 的最近活跃时间、沉淀计数与活动流水；管理员可看全员 Agent 目录。

## 人工导入聊天记录（v1.6.1）

不经 Agent 也能沉淀：项目详情「记录」tab 的「**导入聊天记录**」，把微信/飞书里复制的聊天整段粘贴、
或直接上传导出的 `.txt` 文件，系统按规则解析成对话轮次预览（支持微信时间在前/说话人在前、
飞书短日期/三行式、冒号誊抄等常见格式），确认后存为聊天记录；认不出格式会按纯文本原样保存，
原始文件自动作为附件留档。全程不经过大模型，聊天内容不外发。

## 安全与边界

- 回传的对话与记录**默认仅内部可见**，不会推送给客户；同步客户需在记录上显式勾选；
- 项目经理可退回（删除）不合适的 Agent 沉淀内容；
- 停用或删除 Agent 即其 Key 立刻失效，已沉淀的资源保留（归属标记不丢）；
- Key 疑似泄露时在「Agent 协作」页一键换 Key，旧 Key 即刻作废。

## 常见问题

**Q: 我的 Agent 在第三方平台上，对话记录本来就留在平台里，为什么还要回传？**
平台里的对话只有你自己看得到，也无法与项目关联。回传后它成为项目过程资料的一部分——接手的同事、复盘的经理都能看到"当时为什么这么决定"。

**Q: 一个人可以注册几个 Agent？**
不限。建议按用途拆（调研助手、代码巡检、纪要整理各一个），来源标注更清晰。

**Q: 注册的 Agent 和「智能助手」什么关系？**
「智能助手」是系统内置的对话入口（会话可手动挂到项目）；「Agent 协作」管理的是你在外部平台自养的 Agent。两者沉淀的对话都进项目时间线。
