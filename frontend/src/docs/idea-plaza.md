# 创意中心：想法从哪来，到哪去

> v2.10.0 · 后台菜单「创意中心」· 适用：全体同事发想法与讨论、项目经理把想法落成里程碑、Agent 经 MCP 读写

## 1. 它解决什么

项目都从一个想法开始。以前想法散在聊天群、会议和各人脑子里：聊过就沉了，没人知道后来做没做、为什么没做。

创意中心是一个**面向全公司、不绑定任何项目**的广场。想法在这里发出来、聊清楚，再分配到具体项目里变成里程碑。它是生产流程的第一环：

```
想法(创意中心) → 里程碑(项目) → 任务(路径图) → 分配到人或机器
```

## 2. 三个概念

| 概念 | 是什么 | 谁能动 |
|---|---|---|
| 话题 | 广场里的频道，比如「产品想法」「客户需求」「效率改进」 | 谁都能开；创建人和经理能改、能归档 |
| 想法 | 话题下的一条帖子：标题 + Markdown 正文 + 图片/附件 | 谁都能发；作者和经理能改、能删 |
| 讨论 | 想法下面的评论与回复，可以 @同事 | 谁都能说；自己的评论自己能删 |

想法有三种状态：

- **讨论中**：默认状态
- **已转里程碑**：已经分配到某个项目，想法上会显示去向
- **搁置**：暂时不做，经理可以搁置，也可以恢复讨论

## 3. 怎么用

**发想法**：点右上「💡 发想法」，选话题、写标题和内容。不用写完整，写清「是什么、为什么值得做、大概怎么做」就够。工作台的快捷操作里也有「💡 提想法」。

**讨论**：点开任意想法，右侧抽屉里看全文和讨论。

- 觉得值得做就点 👍，列表可以按「最多赞」排序
- 评论里输入 `@` 选同事，对方会立刻收到通知
- 点「回复」是回某一条评论；讨论只有两层，不会越叠越深
- 有人评论了你发的想法、回复了你的评论，会进你的每日动态摘要，不逐条打扰

**AI 总结讨论**：讨论多了，点「✨ AI 总结讨论」。AI 会把讨论收拢成：已有共识、仍有分歧、待回答的问题、建议下一步。总结存在想法上，后来的人不用爬楼。

**置顶 / 搁置**：经理在想法详情的「更多」里操作。

## 4. 把想法转成里程碑

想法聊清楚、决定要做了，由项目经理或管理员点「🚩 转为里程碑」：

1. **选项目**：只能选自己能看到的项目
2. **选去向**：
   - **新建里程碑**：填名称、完成定义、范围说明。点「✨ AI 起草」，AI 会根据想法和讨论写好这三项，并列出动工前要先问清的事；它会参考这个项目已有的里程碑，避免重复
   - **并入已有里程碑**：想法只是已有里程碑的一部分时用
3. **确认**：想法状态变为「已转里程碑」，讨论区自动留一条去向说明，作者收到通知。新建的里程碑描述末尾会带上出处（`—— 来源: 创意中心想法 #编号「标题」`）

转完后点「去路径图拆任务 →」，直接落到该项目规划 Tab 里的这个里程碑，用那里的「✨ AI 助手」生成任务草案、审核、应用（见[里程碑路径图](/docs/roadmap)）。

> 一条想法只能转一次。AI 起草的内容是草稿，转之前请过一遍。
>
> 广场全员可见，但项目不是：想法分配到了哪个项目、哪个里程碑，只对能看到那个项目的人显示；其他人只看到「已转里程碑」。

## 5. 权限

| 动作 | 谁可以 |
|---|---|
| 看、发想法、开话题、评论、点赞、AI 总结 | 全员 |
| 改 / 删想法 | 作者本人、经理、管理员 |
| 置顶、搁置、改别人的话题 | 经理、平台运营、管理员 |
| 转为里程碑、AI 起草里程碑 | 项目经理、管理员（且项目在自己的数据范围内） |

权限点为 `idea.view` / `idea.create` / `idea.convert` / `idea.manage`，可在「基础配置 → 角色权限配置」里调整。

## 6. Agent 怎么用（MCP）

| 工具 | 用途 |
|---|---|
| `list_idea_topics` | 列话题，拿 topicId |
| `create_idea_topic` | 开话题 |
| `list_ideas` | 列想法，可按话题/状态/关键词筛选 |
| `get_idea` | 读全文、讨论、AI 总结、去向 |
| `create_idea` | 发想法（会带「经 Agent 发布」标记） |
| `add_idea_comment` | 评论或回复 |
| `summarize_idea` | AI 总结讨论 |
| `draft_idea_milestone` | AI 起草里程碑，只返回草稿 |
| `convert_idea_to_milestone` | 转为里程碑（调用前要和用户确认项目与里程碑名称） |

典型用法：会后让 Agent 把会议里冒出来的想法逐条 `create_idea` 进对应话题；周会前让它 `list_ideas` + `summarize_idea` 出一份「本周值得讨论的想法」；决定要做的，`draft_idea_milestone` 给你看过后 `convert_idea_to_milestone`，再用 `generate_decomposition_draft` 拆任务。

## 7. 常见问题

**AI 按钮提示「还没有可用的大模型」**：请管理员到「基础配置 → 大模型配置」添加并启用一个配置。不影响手工发想法和转里程碑。

**话题删不掉**：只有空话题能删。有想法的话题可以归档：归档后不能再发新想法，已有的照常可看。

**转错项目了**：到那个项目里删掉或改掉里程碑即可；想法这边的去向记录目前不能撤回，在讨论区补一句说明。
