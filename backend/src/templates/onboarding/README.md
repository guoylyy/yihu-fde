# 开发配置包 · 上手指南

你好，{{USER_NAME}}！这个压缩包是你的**个人开发配置包**，照下面的步骤走完，你就能用「平台任务 + AI 协作」的方式开始开发交付了。

> ⚠️ 包里的 `.mcp.json` 含有你的**个人专属密钥**（以 `fde_` 开头），等同于你的账号身份：
> - 不要发给任何人，不要提交进任何 git 仓库
> - 如果泄露了，去 平台 → 头像菜单 → API Key 里吊销它，再回「开发上手」页重新下载一份

## 第 1 步：安装工具（一次性）

1. 安装 [Claude Code](https://claude.com/claude-code)（终端里运行 AI 编程助手）
2. 确认本机装了 git，并且你的 Gitee 账号已被拉进团队仓库（找组长要权限）

## 第 2 步：放置配置文件

把包里的文件按下面的位置放好（假设你的项目代码在 `~/work/my-project`）：

```
~/work/my-project/
├── .mcp.json                     ← 包里的 .mcp.json 放到项目根目录
├── CLAUDE.md                     ← 包里的 CLAUDE-template.md 复制过来改名, 按占位符填写(见下)
└── .claude/
    └── skills/
        └── fde-tasks/
            └── SKILL.md          ← 包里的 skills/fde-tasks/SKILL.md 放到这里
```

- `.mcp.json`：让 Claude Code 连上平台（取任务、回写进度都靠它）
- `fde-tasks` 技能：教 AI 按团队标准流程干活（开工 → 拆分 → 开发 → 收工回写），内置**巡检模式**（定时自动取任务开发，进阶用法）
- `CLAUDE-template.md`：**项目开发说明书模板**。复制到项目仓库根目录改名 `CLAUDE.md` 并按 `<占位符>` 填写（技术栈/启动/验证/发布策略）——AI 靠它知道怎么跑项目、怎么验证、能不能上线。发布策略一行必填，模板细节见 /docs/auto-dev 第 4 节

## 第 3 步：验证连接

在项目目录里启动 `claude`，对它说：

```
开工
```

如果它列出了**你在平台上的待办任务**，说明全部打通了 ✅
（此时回到平台「开发上手」页刷新，前两步会自动点亮）

## 第 4 步：按标准流程干活

日常开发循环（AI 会带着你走，你只需要记住三个口令）：

| 口令 | 时机 | AI 会做什么 |
|---|---|---|
| `开工` | 每天开始 | 拉取你的待办任务，和你确认做哪个，置为进行中并拆子任务 |
| （开发中） | 写代码时 | 和你协作开发；**提交信息末尾带上任务号**，如 `fix: 修复登录 #123`，平台会自动把提交挂到任务时间线 |
| `收工` | 任务做完 | 汇总做了什么、写回任务评论、把任务置为「生产完成」 |
